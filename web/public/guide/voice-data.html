내 목소리는 저장되나 — 음성 데이터 처리

따로 동의하지 않으면 저장하지 않습니다. 녹음한 음성은 채점이 끝나면 곧바로 지우는 것이 기본이고, 음성 저장과 AI 모델 학습 활용에 선택 동의한 경우에만 보관합니다. 이 글은 개인정보처리방침의 내용을 풀어 쓴 것이며, 정확한 기준은 개인정보처리방침입니다.

동의하지 않은 경우

녹음한 음성은 억양을 분석해 점수를 매기는 데에만 씁니다. 한 문항을 여러 번 녹음했다면 마지막에 올라간 녹음 하나만 채점합니다. 채점하는 동안 음성은 서비스 서버와 분석 서버의 메모리와 임시 파일로만 흐르고, 분석이 성공하든 실패하든 즉시 삭제합니다. 서버가 비정상 종료돼 임시 파일이 남는 경우에 대비해 30분이 지난 임시 파일을 지우는 청소 작업도 둡니다. 데이터베이스에는 음성을 담는 항목 자체가 없습니다. 기기에서도 녹음을 파일로 저장하지 않습니다.

다만 브라우저 웹에서는 동의하지 않아도 음성 없이 분석 정보는 남깁니다. 문항과 세션의 식별자, 고른 출신 지역, AI가 매긴 억양 점수 같은 값으로, 억양 분석 모델 개선과 출신 지역별 응시자 구성 파악에 씁니다. 이름이나 연락처처럼 사람을 직접 알아볼 수 있는 값은 들어 있지 않습니다.

동의한 경우

음성 저장과 학습 활용 동의는 선택 사항이고, 동의하지 않아도 응시와 결과 확인에 제한이 없습니다. 웹에서는 응시할 때마다 동의 여부를 묻고, 처음에는 체크되어 있지 않습니다. 동의하면 소리 내어 읽은 문항마다의 음성과 분석 정보를 AWS 서울 리전의 저장소에 보관해 억양 분석 AI 모델을 학습시키고 개선하는 데 씁니다. 저장할 때 암호화하고, 읽기 권한은 모델 학습 담당자로 제한하며, 보유 기간은 학습 목적을 이룰 때까지입니다.

웹은 계정 없는 익명 세션이라, 세션이 삭제된 뒤에는 저장된 음성이 누구의 것인지 알 수 없습니다. 그래서 그 뒤에는 개별 삭제 요청을 받아도 해당 음성을 찾아 드릴 수 없습니다. 이용 후기에 답변 받을 이메일 주소를 적어 보낸 경우에만 그 후기를 통해 찾을 수 있습니다.

결과와 세션

테스트 결과와 세션은 테스트를 끝낸 때부터 24시간 뒤 자동으로 삭제됩니다. 끝내지 않은 세션은 만든 지 30분이 지나면 만료되어 지워집니다. [다시 테스트하기]를 누르면 이전 세션과 결과를 즉시 삭제하지만, 위에서 따로 보관한다고 적은 음성과 분석 정보는 이때 지워지지 않습니다. 카카오톡으로 결과를 공유할 때 전달되는 것은 등급 카드와 테스트 링크이고, 점수와 세션 정보, 음성은 전달하지 않습니다. 음성과 세션, 결과는 국외로 이전하지 않습니다.
