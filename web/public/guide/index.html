사투리 이야기

Accentury를 만들면서 우리가 직접 정하고 측정한 것들을 글로 정리했습니다. 테스트가 어떤 순서로 진행되는지, 점수와 등급은 어떻게 정해지는지, 녹음한 목소리는 어떻게 다루는지를 실제 서비스에 적용된 기준 그대로 적었습니다.

  • 사투리 억양 테스트는 어떻게 진행되나 — 마이크 점검부터 결과 화면까지 화면 순서대로
  • 다섯 등급은 어떻게 나뉘나 — 억양·단어·종합 점수와 다섯 등급
  • 목소리에서 억양을 꺼내는 법 — 피치 곡선 — 녹음 화면의 실시간 곡선이 만들어지는 과정
  • 음정 추출 모델을 고르기까지 — RMVPE 벤치마크 기록 — 잡음을 섞어 후보 모델을 비교한 측정 기록
  • 녹음 환경이 결과에 미치는 영향 — 녹음 형식과 녹음 직후 검사하는 항목
  • 내 목소리는 저장되나 — 음성 데이터 처리 — 음성이 지워지는 시점과 선택 동의
  • 자주 묻는 질문 — 마이크 권한, 다시 녹음, 결과 공유와 보관
  • Accentury를 만든 이유와 팀 — 무엇을 만들고 싶었고 누가 만드는지
