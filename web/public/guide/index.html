테스트는 이렇게 진행됩니다

문제는 억양을 보는 음성 문항과 사투리 단어를 묻는 단어 문항이 섞여 나옵니다. 음성 문항은 화면의 문장을 소리 내어 읽어 녹음하고, 단어 문항은 보기 가운데 하나를 고릅니다. 문항을 다 풀면 서버가 억양 점수와 단어 점수를 합산해 다음 다섯 등급 가운데 하나로 판정합니다.

  1. 외지인
  2. 여행객
  3. 사투리 호소인
  4. 명예주민
  5. 경남 토박이

사투리 이야기

Accentury를 만들면서 우리가 직접 정하고 측정한 것들을 글로 정리했습니다. 테스트가 어떤 순서로 진행되는지, 점수와 등급은 어떻게 정해지는지, 녹음한 목소리는 어떻게 다루는지를 실제 서비스에 적용된 기준 그대로 적었습니다.

  • 사투리 억양 테스트는 어떻게 진행되나마이크 점검부터 결과 화면까지 화면 순서대로
  • 다섯 등급은 어떻게 나뉘나억양·단어·종합 점수와 다섯 등급
  • 목소리에서 억양을 꺼내는 법녹음 화면의 실시간 곡선이 만들어지는 과정
  • 녹음 환경이 결과에 미치는 영향녹음 형식과 녹음 직후 검사하는 항목
  • 내 목소리는 저장되나음성이 지워지는 시점과 선택 동의
  • 자주 묻는 질문마이크 권한, 다시 녹음, 결과 공유와 보관
  • Accentury를 만든 이유무엇을 만들고 싶었나
홈 소개 사투리 이야기 개인정보처리방침 문의

녹음한 음성은 따로 동의하지 않으면 분석이 끝난 뒤 바로 삭제하고, 테스트 결과는 24시간만 보관합니다. 자세한 내용은 개인정보처리방침에 적어 두었습니다.
