Accentury 계정 삭제(회원 탈퇴) 안내

Accentury - 사투리 억양 테스트 앱(Android·iOS)의 계정을 삭제하는 방법을 안내합니다. 계정은 앱 안에서 바로 삭제할 수 있고, 앱을 지웠거나 쓸 수 없는 경우에는 이메일로 삭제를 요청할 수 있습니다. 웹(accentury.app)에는 회원가입과 로그인이 없어 삭제할 계정이 없습니다.

앱 안에서 탈퇴하기

  1. 앱 화면 오른쪽 위의 톱니 모양 [설정]을 누릅니다.
  2. 설정 화면의 계정 항목에서 [회원 탈퇴]를 누릅니다.
  3. 안내 창의 내용을 확인하고 [탈퇴]를 누릅니다.

iPhone에서 Apple로 로그인한 계정은 [탈퇴]를 누른 뒤 Apple 확인 창이 한 번 더 뜹니다. 이 확인은 Apple 로그인 연결을 끊는 데 쓰입니다. 확인 창에서 취소하면 탈퇴하지 않습니다.

앱 없이 이메일로 요청하기

아래 주소로 가입하실 때 쓴 로그인 방식(카카오, 네이버, 구글, Apple 가운데 하나)과 계정에 등록된 이메일 주소를 적어 계정 삭제를 요청해 주세요. 본인임을 확인한 뒤 지체 없이 계정을 삭제하고 결과를 회신해 드립니다. 앱을 다시 설치하실 필요는 없습니다.

탈퇴하면 지워지는 것과 남는 것

  • 이메일, 이름 같은 계정 정보는 지체 없이 파기합니다.
  • 모든 기기에서 로그인이 풀립니다.
  • 테스트 결과는 계정과의 연결을 끊어 누구의 것인지 알 수 없는 상태로 남고, 원래 보관 기간이 지나면 삭제됩니다.
  • 탈퇴는 되돌릴 수 없습니다. 같은 로그인 방식으로 다시 로그인하면 새 계정으로 가입됩니다.
